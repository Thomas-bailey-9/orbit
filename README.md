# ORBIT

Independent, cinematic car-discovery website: explore a car from every angle, then continue on the manufacturer's official website.

**Status:** in development — B00 foundation preview. Preview: https://thomas-bailey-9.github.io/orbit/

```bash
npm ci
npm run dev        # http://localhost:5173/orbit/
npm run build      # type check + production build
```

Project documentation lives in [`docs/`](docs/) — start with `PROJECT_BRIEF.md`, `BUILD_STATUS.md` and `FILE_MAP.md`.
