# ORBIT — Project brief

Full approved reference: [ORBIT_Project_Reference_v1.md](./ORBIT_Project_Reference_v1.md) (authority order is in its §1).

## Purpose
ORBIT is a silent, cinematic, independent car-discovery website. Visitors choose a brand, explore a real 3D car, inspect photographs and specifications, compare two cars, save configurations on their device, then continue to the official manufacturer website.

## Scope
- Initial brands: BMW, Porsche, Mercedes-Benz. Aim for three distinct models per brand (sporty car, saloon, mid-size SUV), adapted to the real range.
- UK market, indicative GBP prices with stated basis and check date.
- Data-driven: more brands and models are added by adding records, never new pages.
- Build one complete verified car before populating the rest.

## Core journey
Opening → brand selection → model panels → asset loading → headlight introduction → Reveal → 3D showroom → exterior → interior → specifications → official link.
Alternate paths: Browse all cars, comparison, saved cars, shared model-and-colour links.

## Exclusions
No payments, accounts, enquiry forms, checkout, sound, "recently viewed", or automatic related-car recommendations. Official pages are destinations, not proof of stock.
